# 刻蚀与薄膜沉积设备点检 SOP

## 1. 目的
规范刻蚀机、等离子体增强化学气相沉积（PECVD）、物理气相沉积（PVD）等设备的日常点检与异常处置，降低因设备状态劣化导致的批次质量异常。

## 2. 计划点检项目（每班次）
- 腔体压力与抽气速率：检查压力控制回路的设定值与实测值偏差，偏差持续超过 5% 需记录并上报。
- 射频功率与匹配网络：检查正向/反射功率比，反射功率异常升高通常指向匹配网络或电极污染。
- 气体流量与配比：核对各支路质量流量控制器（MFC）读数与配方设定值的一致性。
- 静电吸盘（ESC）温度与背吹压力：温度漂移会显著影响刻蚀速率均匀性。
- 腔体内壁与部件累积：观察沉积物累积是否超出点检窗口。

## 3. 关键参数漂移的常见原因
1. 传感器本身漂移或零点偏移：表现为多条相关信号同向偏移。
2. 管路堵塞或漏气：压力与流量信号同时异常，抽气时间变长。
3. 匹配网络老化：反射功率上升，功率相关信号波动增大。
4. 部件磨损更换周期未到而提前劣化：表现为刻蚀速率或沉积速率缓慢下降。
5. 冷却系统能力下降：温度类信号上抬，且与设备负载相关。

## 4. 处置步骤
1. 停止在该设备上投入新批次，完成当前批次并加严抽检。
2. 调取异常发生时段的全部工艺信号，按信号簇定位异常工序站。
3. 执行“零点校验—泄漏检查—部件检查”三步排查。
4. 若校验后偏差仍存在，按备件清单更换可疑部件。
5. 复机后空运行两个监测批次，确认信号回到基线范围再恢复投料。

## 5. 复测与放行
复机后必须重新采集工艺信号并复算风险概率。风险概率回落至基线不良率附近（通常低于 10%）方可解除冻结。若复算后风险仍未回落，判定为“未修复”，升级为二级异常并重新派工。
