# 前道工序设备维护总则与响应分级

## 1. 适用范围
本规范适用于前道工序段（扩散、光刻、刻蚀、薄膜沉积、离子注入、清洗、化学机械抛光等）生产设备与工艺测量点的日常维护、异常响应与工单流转。适用于晶圆批次（Lot）在制过程中由过程信号触发的质量风险处置。

## 2. 术语
- 批次（Lot）：一次连续投入生产的晶圆集合，对应数据集中的一条生产实体记录。
- 工艺信号：来自设备的传感器读数与过程测量点数值，包括温度类、压力类、流量类、功率类、时间类、位置类信号。
- 信号簇：将同一工序阶段内高度相关的信号归并后的集合，用于判定异常归属的工序站。
- 风险概率：风险预测模型给出的“该批次出现质量异常”的概率估计，属于统计估计，不等同于事实判定。

## 3. 响应分级
按风险概率与偏差幅度将响应分为三级：
- 一级（高，风险概率 ≥ 0.60 或关键信号偏差 ≥ 5σ）：立即冻结后续投料，按停机流程安排检修，主管工程师必须在场确认。
- 二级（中，风险概率 ≥ 模型阈值且 < 0.60，或关键信号偏差 3σ~5σ）：允许完成当前批次，但必须在规定时间内安排检修，并加强在线抽检。
- 三级（低，风险概率 < 模型阈值）：维持正常生产，纳入趋势观察，下一班次复核。

## 4. 处置闭环要求
任何一次异常响应必须走完“发现—诊断—决策—派工—检修—复测—复盘”七个环节，缺一不可：
1. 发现：在线监测或抽检判定异常。
2. 诊断：确认异常归属的工序站与主要异常信号。
3. 决策：在“立即检修 / 延时检修 / 继续生产”之间给出成本与风险对比。
4. 派工：生成维修工单，明确责任工程师、备件、计划完成时间。
5. 检修：按点检 SOP 执行并记录实测值。
6. 复测：维修复机后重新采集信号并复算风险概率，确认回落至基线水平。
7. 复盘：形成复盘记录，纳入知识库，供后续相似工况检索。

## 5. 责任与记录
- 责任工程师：对异常定位结论与检修动作的正确性负责。
- 工艺工程师：对批次放行、返工或报废的质量结论负责。
- 值班主管：对停机决策的批准与交期影响的确认负责。
- 所有决策依据、工具调用记录与人工确认记录必须留痕，可追溯到具体批次与时间戳。
